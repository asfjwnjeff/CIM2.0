## 关键结论速查

### 业界两大架构模式

| | 统一 Party 模型 | 独立分域模型 |
|---|---|---|
| 代表 | SAP BP、金蝶 AMDM | 用友 MDM、中远海运 |
| 核心思路 | 一个法律实体一条记录，角色是标签 | 客户域和主体域各自独立建模 |
| CIM 适用性 | **推荐**：CIM 当前场景高度匹配 | 如果未来扩展到全品类供应商可参考 |
