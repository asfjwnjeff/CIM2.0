## 1. 中远海运集团 —— 物流/供应链行业标杆

| 维度 | 内容 |
|------|------|
| 背景 | 2016 年两大央企重组成立，数百套系统独立运行，数据分散、标准各异 |
| 主数据域 | **9 大域**：客户、供应商、会计科目、银行代码、贷款人、船舶、航运货种、航运港口、航运燃油 |
| 客户/供应商关系 | **分域独立管理**，各有独立管理细则 |
| 技术栈 | SAP Portal（展示交互）+ SAP BPM（流程管理）+ SAP MDM（建模存储）+ SAP PI（数据分发） |
| 管控模式 | "五位一体"：信息员-审核员-分级审批-质量监控-绩效考核 |

**关键经验**：
- 每域有独立的管理细则文档
- 通过 SAP PI 实现主数据跨系统分发
- 建立"五位一体"的持续治理机制

## 2. 某世界领先物流集团 —— 外部单位统一模型

| 维度 | 内容 |
|------|------|
| 背景 | 端到端供应链解决方案提供商，300+ 信息系统 |
| 主数据域 | 内部单位、员工、财务、业务基础（港口/机场等）、外部单位（客户+供应商）、物料设备 |
| 客户域处理 | 采用"外部单位"统一模式 —— **以法律实体为统一入口，通过"业务角色"标签区分客户/供应商/既是客户又是供应商** |
| 质量保障 | 引用工商数据（天眼查/企查查）作为基准校验 |

**关键经验**：
- 外部单位统一模型适合供应链行业多角色场景
- 工商数据可作为主数据真实性的基准校验源

## 3. 华为 —— 数据治理方法论

| 维度 | 内容 |
|------|------|
| 核心理念 | "一数一源、一源多用" —— 建立企业级主数据模型，打破系统孤岛 |
| 方法论 | "4层保障 + 2个抓手" |

**4层保障**：
| 层次 | 说明 |
|------|------|
| 政策保障 | 公司层面统一遵从的数据管理总纲 |
| 流程保障 | 建立数据管理流程，重大决议由企业变革指导委员会决策 |
| 组织保障 | 按领域任命 Data Owner 和数据管家 |
| IT落地保障 | 建设数据底座和统一IT平台 |

**2个抓手**：
| 抓手 | 说明 |
|------|------|
| 信息架构 | 数据资产目录 + 数据标准 + 数据模型 + 数据分布 |
| 数据质量 | 从"设计质量"和"执行质量"两个维度度量 |

**演进路径**：
- 第一阶段（2007-2017）：引入 IBM 数据管理框架，建立统一信息架构与标准
- 第二阶段（2017-至今）：建设数据底座，实现"数据业务可视、随需共享、敏捷自助、安全透明"

华为云对外输出的 EsMDM 主数据管理平台即基于自身实践的产品化输出。

## 4. 中兴通讯 —— DCMM 最高等级

中兴的数据治理主要基于自研的**数字星云（Digital Nebula）平台**和 **VMAX 数智中台**，荣获 2024 年 DCMM 优化级（最高等级）认证、2025 年 DAMA "数据治理最佳实践奖"。

关键数据：
- 接入 200+ 应用系统
- 集成 10000+ 工作流
- 上架 1200+ 数据产品
- 转型路径："线下 → 线上 → 在线 → 智能在线"

## 8. 对 CIM2.0 的启示

1. **中远海运的分域模式**：如果 CIM 未来范围扩展到供应商、物料等，可参考 9 大域的划分方法
2. **某物流集团的"外部单位统一模型"**：最接近 CIM 当前场景——以法律实体为入口，角色标签区分业务身份
3. **华为的"一数一源"原则**：CIM 作为客户主数据源头，COS/CPQ/TMS/WMS/DMS 只消费不反向修改
4. **Bayer 的自动化率**：智能审批规则可大幅降低人工审核工作量
